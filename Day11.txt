-----------------SET OPERATORS--------------

UNION : combines results frim two queries and removes duplicates rows , columns must have rhe same number and type

UNION ALL : Combines results from two queries and includes all rows ,including duplicates colmns must have the same number and type

INSERT : returns rows that are common both queries .columns must have the same number and 
NOTE: MYSQL doesn't support intersect directly


MINUS : Returns rows from the first query that are not present in the second query . Columns must have the same number and type
NOTE:MYSQL doesn't support minus directly

-------------------------------------------JOINS-------------
INNER JOIN --> MATCHED RECORDS FROM BOTH TABLES
LEFT JOIN --> MATCHED RECORD+ LEFT TABLE RECORDS
RIGHT JOIN --> MATCHED RECORD + RIGHT TABLE RECORDS
FULL JOIN --> INNER JOIN + RIGHT JOIN + LEFT JOIN
CROSS JOIN --> IT PERFORMS CARTESIAN PRODUCT
