Clauses:

Clauses are used to control how data is selected, filtered, grouped, sorted or modified in SQL Queries

Think of cluases like instructions given to the database

1.Where clause

Filtered records based on specified cond where clause can be used as compariision operators,logical operators etc 

Syntax:

Select column1,column2.....
from table
where condition;

2.Group by clause:

The group by clause is used to grp rows having the same value in one or more columns.It is commonly used with aggregate functions such as
sum(),min(),max(),avg(),count()

Syntax:

select column-name,aggregate-function(column-name)
from table-name
group by column;

3.Having Clause:

The having clause is used to filter grouped records after group by clause.It is similar to where but it works on grouped instead of individual rows

Syntax:

Select column-function(column-name)
from table-name group by column-name having condition;

4.Order by clause 

The order by clause is used to sort the result set in ascending(ASC) or Descending (DESc) order

(ASC): ascending order by default

Syntax:

select column-name
from table-name
order by column-name asc;
